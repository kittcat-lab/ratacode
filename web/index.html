RATACODE
la terminal de trabajo bruto
TRABAJO BRUTO

Manos baratas para tu agente o tu chat.

Le pasas el trabajo pesado a modelos baratos (B.AI, OpenRouter, DeepSeek) y el resultado vuelve a tu agente o a tu chat. Es DSH con la cara de RATACODE: ni el motor ni el frontend se tocan.

Instalación · un comando, Windows + Node 24

npm i -g ratacodey luego: ratacode

Mientras el paquete no esté en npm, desde el repositorio:

npm i -g github:kittcat-lab/ratacodey luego: ratacode

Si npm se atasca con esa (resuelve GitHub por git), el tarball del repositorio: git clone https://github.com/kittcat-lab/ratacode · cd ratacode && npm pack · npm i -g ./ratacode-0.1.0.tgz. El botón de aquí abajo lo explica entero.

Las 3 formas de usarlo

01 Navegador

ratacode abre la terminal en tu navegador (puerto 3777). La URL con su token queda en %USERPROFILE%\.ratacode\url.txt.

02 Headless

ratacode headless "encargo": sin pantalla, encargo por terminal y la entrega en un fichero.

03 MCP

ratacode mcp: ChatGPT web, Claude Code, Codex, Rowboat u OpenClaw le mandan tareas (list_models → run_task → get_task_result).

Las 3 claves · las pones tú, nunca viajan en el paquete

B_AI_API_KEYOPENROUTER_API_KEYDEEPSEEK_API_KEY

Se ponen la primera vez (Ajustes → Models) o como variables de entorno.

Seguridad

  • Carpeta cerrada: todo vive en %USERPROFILE%\.ratacode, nunca en ~/.dsh. Las tareas MCP solo trabajan dentro de su working_directory.
  • Las claves no salen: se usan, no se cuentan — ni por el MCP, ni por el cuaderno, ni por los shells de sus agentes.
